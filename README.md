# Raspberry Pi Zero - Image Dataset for Computer Vision

This repository contains a custom image dataset collected using a **Raspberry Pi Zero**. The dataset was created to build and validate object detection models, consisting of images captured in real-world conditions with manual bounding box selection for object identification.

## 📌 Dataset Overview

- **Source Hardware:** Captured directly using a Raspberry Pi Zero camera module.
- **Content:** Diverse images collected for model training and real-world inference tests.
- **Annotations:** Manual bounding box selection applied to identify and segment target objects.
- **Purpose:** Used to train computer vision models and evaluate object identification accuracy against a pre-trained model.

## 📁 Usage

This dataset can be used for:
- Training custom object detection algorithms (YOLO, SSD, Faster R-CNN, etc.).
- Benchmarking inference accuracy on edge-captured images.
- Computer vision experiments and educational projects.
